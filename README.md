# 📱 Student Performance & Mental Health Prediction Using Machine Learning

This project predicts **academic performance** and **mental health
conditions** (Stress, Anxiety, Depression) of students based on **mobile
phone usage, study habits, sleep patterns, and social interactions**
using Machine Learning techniques.

It also provides **personalized suggestions** and a **risk assessment**
to help improve students' academic and mental well-being.

------------------------------------------------------------------------

## 🚀 Project Features

-   🎓 Predicts **Academic Performance Level** (Low / Medium / High)
-   🧠 Predicts **Stress, Anxiety, and Depression Levels**
-   🤖 Uses **Random Forest Classifier**
-   🧑‍🎓 Accepts **real-time student input**
-   💡 Gives **personalized lifestyle suggestions**
-   🚨 Displays **mental health risk warning**
-   📊 Visualizes academic performance distribution

------------------------------------------------------------------------

## 📂 Dataset

**File:** `teen_phone_addiction_dataset.csv`

### Attributes

-   Age
-   Gender
-   School_Grade
-   Daily_Usage_Hours
-   Sleep_Hours
-   Social_Interactions
-   Academic_Performance

> If `Study_Hours` is not present, it is generated automatically.

------------------------------------------------------------------------

## 🧠 Machine Learning Models

  Model           Purpose
  --------------- ----------------------
  Random Forest   Academic Performance
  Random Forest   Stress Level
  Random Forest   Anxiety Level
  Random Forest   Depression Level
